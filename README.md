# 转正倒计时

2–8 人联机的第一人称职场生存游戏。你是鲸跃科技的实习生：五天之内抢 KPI、躲总监、坑同事，排名靠前的人才能转正。

## 玩法

- 每天从合租屋起床：抢洗漱台、换衣服、抢早餐，过两条马路，挤地铁，9:00 前打卡。
- 到岗后做任务赚 KPI，可以摸鱼回精力，但被总监或 HR 看到会吃警告，三次警告劝退。
- 第 2、4 天外派到物流仓库，要躲叉车。
- 同事之间可以推人、丢香蕉皮、抢东西、举报、甩锅。每天 KPI 第一有奖励，最后一名记警告。

## 操作

WASD 移动 · 鼠标转向 · 空格跳跃 · E / F 互动 · C 推人 · V 丢香蕉皮 · Q 摸鱼 · R 举报 · G 吃零食 · X 丢弃 · Tab 排名

## 运行

需要 Node 22.18 以上（服务端直接运行 TypeScript）。

```bash
npm install
npm run dev      # 客户端 http://localhost:5173 ，房间服务器 :3001
```

同一局域网的朋友打开 `http://<你的 IP>:5173`，输入房间号加入。

```bash
npm test         # 规则测试
npm run build    # 打包客户端
npm start        # 由服务器同时提供打包后的客户端
```

## 结构

- `shared/` 地图、常量、协议、导航，客户端和服务端共用
- `server/` 房间服务器，`server/sim/` 是纯函数的游戏规则
- `client/` Three.js 渲染、界面和输入，所有模型都是代码生成的
- `tests/` vitest 测试
